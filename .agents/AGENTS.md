# AGENTS.md - Reglas de Estilo del Proyecto Indisutex

## 🎨 Tipografía y Grosor de Texto (Regla Fundamental)
- **NUNCA usar negrillas pesadas o excesivas** (`fontWeight: 800` o `fontWeight: 700` masivo).
- Usar como máximo **`fontWeight: 600`** para títulos, subtítulos, valores de tablas y botones.
- Mantener una jerarquía visual sobria, refinada y limpia utilizando la fuente **Poppins** (`fontFamily: "'Poppins', sans-serif"`).
